## ✨ Особенности игры

- **100% C#**: Вся логика головоломки, анимация, интерфейс и система звуков написаны строго на C# без использования GDScript.
- **Два режима игры**: Свободный выбор параметров и сюжетная кампания с разблокировкой уровней.
- **Интерактивный Drag-and-Drop**: Плавное перетаскивание дисков мышью с цветовой индикацией допустимости хода.
- **Рекурсивный решатель (AI)**: Автоматическое решение головоломки за минимально возможное число ходов с регулировкой скорости и паузой.
- **Процедурный звук**: Встроенный генератор звуков на основе синтеза частот (без внешних тяжелых аудиофайлов).
- **Сохранение прогресса**: Локальное сохранение рекордов, времени и заработанных звёзд (`user://hanoi_save_data.json`).

## 🎮 Игровые режимы

### 1. Свободная игра (Free Play)
- Настройка количества дисков от **3 до 10**.
- **Ручной режим**: игрок сам собирает башню, получая оценку от **0 до 3 звёзд** в зависимости от эффективности ходов.
- **Автоматический режим**: компьютер демонстрирует оптимальное математическое решение.
  - Плавная визуализация перемещения по дуге.
  - Управление воспроизведением: **Старт/Пауза**, **Пошаговый ход**, **Сброс**.
  - Настройка скорости: `0.5x`, `1x`, `2x`, `5x`, `Мгновенно`.

### 2. Кампания (Уровни 1–8)
- 8 последовательных уровней сложности:
  - **Уровень 1**: 3 диска (7 ходов)
  - **Уровень 2**: 4 диска (15 ходов)
  - **Уровень 3**: 5 дисков (31 ход)
  - **Уровень 4**: 6 дисков (63 хода)
  - **Уровень 5**: 7 дисков (127 ходов)
  - **Уровень 6**: 8 дисков (255 ходов)
  - **Уровень 7**: 9 дисков (511 ходов)
  - **Уровень 8**: 10 дисков (1023 хода)
- **Только ручное прохождение** (подсказка компьютера отключена).
- Открытие следующего уровня только при завершении текущего.

## 📐 Система оценки и формула

Теоретический минимум ходов для башни из $n$ дисков:
$$M_{min} = 2^n - 1$$

| Звёзды | Результат | Критерий |
| :---: | :--- | :--- |
| ⭐⭐⭐ | **Идеально** | $M = M_{min}$ (точно в оптимум) |
| ⭐⭐ | **Отлично** | $M \le M_{min} + \max(2, \lceil 0.35 \times M_{min} \rceil)$ |
| ⭐ | **Хорошо** | $M \le 2 \times M_{min}$ |
| 0 | **Завершено** | $M > 2 \times M_{min}$ |

> **Защита от некорректных ходов**: В игре невозможно совершить невалидный ход (положить больший диск на меньший). Диск покачивается с предупреждающей красной индикацией и мягко возвращается на исходную позицию.

## 🕹 Управление

1. **Drag-and-Drop (Мышь)**:
   - Зажмите ЛКМ на верхнем диске стержня.
   - Переместите на нужный стержень (зеленая зона — ход разрешен, красная — запрещен).
   - Отпустите мышь.
2. **Альтернативный клик**:
   - Кликните по стержню с диском (диск приподнимется).
   - Кликните по целевому стержню для переноса.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/USERNAME/hanoi-towers-godot.git
cd hanoi-towers-godot
```

### 2. Сборка .NET решения
Требуется [.NET SDK](https://dotnet.microsoft.com/download) (8.0 или новее):
```bash
dotnet restore
dotnet build
```

### 3. Запуск игры
- **Через Godot Engine**: Откройте [Godot Engine 4 .NET](https://godotengine.org/download) $\rightarrow$ Нажмите **Import** $\rightarrow$ Выберите `project.godot` $\rightarrow$ Нажмите **Run** (`F5`).
- **Быстрый скрипт (Windows)**: Запустите `RunGame.bat`.

## 🧪 Тестирование логики

В проект встроен автономный набор тестов (`HanoiTests.cs`), проверяющий:
- Корректность формулы оптимального количества ходов ($2^n - 1$).
- Рекурсивный алгоритм решения для всех размеров башен (3–10 дисков).
- Защиту от нелегальных перемещений.
- Правила начисления 0–3 звёзд.

Запуск тестов в консоли:
```bash
godot --headless --path . -- --run-tests
```
